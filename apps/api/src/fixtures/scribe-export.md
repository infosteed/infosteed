# Create a Trail Heat Map

#### [Made by TrailWorks with Scribe](https://scribehow.com/shared/fictional-trail-heat-map)

1\. Navigate to [Trail Map](https://maps.example.com/trails)

2\. Open the layer styling menu

![](https://images.example.com/scribe/step-02.jpeg)

3\. Select **New style**

![](https://images.example.com/scribe/step-03.jpeg)

4\. Enter a name for the style

![](https://images.example.com/scribe/step-04.jpeg)

5\. Select **Create**

![](https://images.example.com/scribe/step-05.jpeg)

6\. Select **Add visualization**

![](https://images.example.com/scribe/step-06.jpeg)

7\. Choose **Heat map**

![](https://images.example.com/scribe/step-07.jpeg)

8\. Select the **Trail visits** field

![](https://images.example.com/scribe/step-08.jpeg)

9\. Confirm the field selection

![](https://images.example.com/scribe/step-09.jpeg)

10\. Continue to the preview

![](https://images.example.com/scribe/step-10.jpeg)

11\. Save the visualization

![](https://images.example.com/scribe/step-11.jpeg)

12\. Confirm the changes

![](https://images.example.com/scribe/step-12.jpeg)

13\. Verify that the trail heat map appears

![](https://images.example.com/scribe/step-13.jpeg)
